# UI Design Alignment v3

## Direction
Keep the same product idea but present it with a light, trustworthy enterprise style.

## Design goals
- clean
- modern
- premium but understated
- mobile-friendly
- easy to read in a live demo

## Recommended theme
- off-white background
- white cards
- navy/slate text
- blue accent
- green for approved actions
- orange for review-needed
- red for rejected or sensitive warnings

## Main screens
### Requester chat page
Left:
- conversation
Right:
- current request summary
- matched asset
- required role
- risk tier
- next action

### Approver page
- card-based request summary
- large approve / reject buttons
- rationale input
- policy section
- easy to open from Slack on mobile

### Audit/doc page
- vertical event timeline
- generated markdown summary preview
- request metadata header

## Design rules
- avoid neon or cyberpunk styling
- avoid dense dashboards
- prefer generous spacing
- one strong accent colour only
- design for quick comprehension over visual novelty
