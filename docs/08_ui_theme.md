# UI Theme Direction

## Theme goal
Make the product feel:
- trustworthy
- modern
- enterprise-ready
- slightly premium
- not flashy or gaming-like

## Recommended visual direction
Use a **light theme** with:
- off-white or very light grey background
- navy / slate text
- muted blue as primary accent
- soft warm grey borders
- subtle card shadows
- rounded corners
- clean spacing

## Avoid
- neon green/purple cyberpunk styling
- overly dark hacker aesthetics
- loud gradients
- cluttered dashboards
- too many badges and pills

## Suggested palette
- Background: `#F7F9FC`
- Surface: `#FFFFFF`
- Primary text: `#142033`
- Secondary text: `#4F5D75`
- Accent blue: `#3B82F6`
- Accent deep blue: `#1D4ED8`
- Success: `#16A34A`
- Warning: `#D97706`
- Danger: `#DC2626`
- Border: `#E5EAF2`

## UI structure
### Requester screen
- left: chat/history
- right: current request summary card
- compact sections for:
  - matched asset
  - required role
  - risk tier
  - next step

### Approver screen
- mobile-friendly card layout
- one request per card
- clear approve / reject controls
- short business justification
- policy summary

### Audit and docs screen
- timeline layout for audit events
- generated markdown/doc summary preview
- compact filters

## Tone
The UI should feel like:
- internal enterprise software
- clean and slightly polished
- safe enough for governance workflows
